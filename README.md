# Watcher (مراقب دراسة الأولاد)

برنامج خفي وقوي لمراقبة دراسة الأولاد على الحاسوب عبر التقاط لقطات الشاشة دورياً ورفعها تلقائياً وبأمان إلى **Google Drive**.

---

## 🌟 الميزات الرئيسية
- 💻 **دعم متعدد الأنظمة**: يعمل على Windows و macOS و Linux.
- ⏱️ **جدولة زمنية مرنة**: التقاط تلقائي كل (3 أو 10 دقائق أو أي فاصل زمني تحدده).
- 🖥️ **دعم الشاشات المتعددة**: يلتقط كافة الشاشات الموصولة بالحاسوب.
- ☁️ **مزامنة Google Drive تلقائية**: باستخدام Service Account بدون طلب تسجيل دخول في المتصفح، مع تنظيم الصور تلقائياً حسب التاريخ واسم الجهاز.
- 🛡️ **حماية ضد العبث (Anti-Tampering)**:
  - معمارية **Watchdog** مزدوجة لمراقبة العمليات وإعادة تشغيلها فوراً إذا أُغلقت.
  - تشفير إعدادات البرنامج بـ `AES-256-GCM` ومفتاح مشتق من كلمة مرور الأب.
  - إخفاء اسم البرنامج في النظام تحت اسم خدمة صيانة (`System Health Diagnostics`).
  - سجل أمني منفصل يرصد أي محاولة لقتل البرنامج أو العبث به.
- 📴 **تحمل انقطاع الإنترنت**: طابور تخزين محلي (Spool Queue) مع حماية ضد استهلاك مساحة القرص (FIFO).

---

## 🚀 البدء السريع

### 1. المتطلبات:
- **Java 17+** مثبت على الجهاز.
- حساب **Google Cloud Service Account** (راجع [دليل إعداد Google Cloud](docs/google-cloud-setup.md)).

### 2. البناء (Build):
```bash
mvn clean package
```
سيتم إنتاج الملف التنفيذي المدمج (Fat JAR) في:
`target/syshealthd.jar`

### 3. التثبيت والتشغيل:
راجع [دليل المستخدم وطرق التثبيت](docs/user-manual.md) لكل نظام تشغيل.
